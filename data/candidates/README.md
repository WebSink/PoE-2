# data/candidates/ — предметы-кандидаты для сравнения

Здесь лежат описания предметов, которые владелец предложил как замену.
Это **вход** для `scripts/gear_analyze.py`, а не игровые данные персонажа.

## Правила

- У каждого файла есть `provenance`: откуда взято описание и чего в нём нет.
- Если пришёл только текст объявления без полного текста предмета из игры, база
  неизвестна — такой файл помечается как частичный, и анализ идёт в режиме
  `declared_only` (без движка).
- Ничего не додумывается: недостающие поля остаются `null`, а не «правдоподобными».
- Цены, продавцы и доступность объявлений здесь не хранятся: торговых интеграций
  в проекте нет.
