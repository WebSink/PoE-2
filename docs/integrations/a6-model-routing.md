## Текущая модель и tool calling

- Сессия выполняется на `deepseek-v4.1-flash`.
- **Tool calling подтверждён фактически:** в этой сессии модель вызывала
  файловые инструменты, shell, `web_fetch`, `install_mcp_server` и MCP-клиент.
- Поле `capabilities` в локальной БД для A6-моделей пустое, поэтому поддержку
  инструментов у `gpt-6.1-sol` нельзя считать подтверждённой без отдельного теста.

## Логические режимы

| Режим | Модель | Назначение | Tool calling |
|---|---|---|---|
| **FAST** | `deepseek-v4.1-flash` | извлечение данных, короткие ответы, рутина | подтверждён |
| **ANALYZE** | `gpt-6.1-sol` | сложный анализ билда, приоритеты, объяснения | **не проверен** |
| **CODE** | `deepseek-v4.1-flash` | правки кода, тесты, git | подтверждён |

Конфигурация без секретов: `config/model-routing.example.json`.

Правило: если модель не поддерживает нужные инструменты — агентная операция
останавливается и требуется смена модели. Не выдавать «модель переключилась»
без подтверждения.

## Экономия

- Не отправлять весь репозиторий: только релевантные файлы/фрагменты.
- Детерминированные расчёты — кодом; LLM не считает статы.
- Не запускать несколько моделей параллельно без необходимости.
- После двух одинаковых неудачных попыток — остановка и отчёт.
- Никаких платных вызовов вне текущей агентной сессии без разрешения.
- Список моделей брать из конфигурации Cherry, а не запрашивать у API ради цен.

## Что не подтверждено

- Фактические тарифы и лимиты A6.
- Поддержка tool calling у `gpt-6.1-sol` в агентном режиме Cherry.
- Наличие/поведение `gpt-6-sol`, `gpt-5.6-sol`, `gpt-6-astra` в текущей подписке.
