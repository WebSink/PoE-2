# Пример: ботинки Sinkov против «Ураганной спешки»

Реальный прогон S5.1 на локальной установке PoB2 `0.23.1` (данные дерева `0_5`),
персонаж Sinkov, Witchhunter, 46 уровень, лига Standard, сценарий
`campaign-act3-normal` (штраф сопротивлений `-20`, монстры 46 уровня).

## Что сравнивается

| | Текущие | Кандидат |
|---|---|---|
| Название | Victory League | Ураганная спешка |
| База | Silk Slippers | **не указана** |
| Редкость | RARE | **не указана** |
| Уровень требования | 36 | 45 |
| Локальная защита | Energy Shield 79 | Armour 115, Energy Shield 34 |
| Модификаторы | +43 ES, +21 жизни, +20 маны, +13% огня, +19% холода, +60 порога оглушения | 20% скорости, +14% огня, +21% молнии, +83 жизни (объявленный итог) |

Текущие ботинки взяты из **актуального** экспорта `data/builds/sinkov-standard.xml`
(слот `Boots`, `itemId 13`), а не из исторического снимка со скриншотов 45 уровня.

Данные кандидата — `data/candidates/sinkov-boots-windrush-partial.json`: то, что
пришло в описании объявления. Полного текста предмета нет, поэтому базовый тип,
редкость, уровень предмета и требования атрибутов **неизвестны**. Придумывать
«похожую» базу, чтобы прогнать движок, нельзя: это была бы не та вещь.

## Команда

```bash
uv run python scripts/gear_analyze.py --slot Boots \
    --item-json data/candidates/sinkov-boots-windrush-partial.json
```

## Как читать результат

Подтверждено и посчитано:

- **Уровень подходит**: 46 ≥ 45.
- **Здоровье**: +62 (объявленный итог +83 против текущих +21). Строки не
  суммировались повторно — связанные бонусы уже внутри 83.
- **Сопротивления**: холод 46% → 27% (−19), молния 35% → 56% (+21), огонь
  остаётся на капе (109% → 110% до капа, 75% после).
- **Потеряно**: +43 ES, +20 маны, +19% холода, +60 порога оглушения.
- **Локальная защита**: ES 79 → 34 (−45), броня 0 → 115 (+115).
- Исходный XML не изменён (sha256 совпадает).

Не посчитано и почему:

- **Скорость передвижения 20%** — без движка не считается: множитель скорости
  зависит от других источников и локальных значений, складывать проценты нельзя.
- **Итоговые броня, ES, EHP, DPS** — только движок.
- **Требования силы/ловкости/интеллекта** — неизвестны без базового типа.
- **Каскад атрибутов** — требует агрегированных требований движка.

Итог: `inconclusive`, предварительно «улучшение» (+33.8 по весам). Формально
балл положительный за счёт молнии и здоровья, но потеря 19% холода и неизвестная
скорость передвижения не позволяют назвать замену улучшением без полного текста
предмета.

## Ограничения этого примера

- Полного текста кандидата нет: база, редкость и требования неизвестны.
- Цена и доступность объявления не проверялись и не утверждаются: торговых
  интеграций в проекте нет.
- Условные и связанные модификаторы кандидата, не попавшие в описание, не учтены.
- Числа действительны только для сценария `campaign-act3-normal`; под эндгейм
  конфигурацией они будут другими.

Полный список ограничений движка — `docs/pob2-limitations.md`.
